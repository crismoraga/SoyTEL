# Product Context

## Overview

SoyTEL convierte conceptos de redes, software, hardware, telecomunicaciones y seguridad en experiencias móviles rápidas. La app funciona local-first para eliminar fricción y puede crecer hacia recorridos colaborativos online.

## Core Features

- Sesiones cortas con XP, niveles, racha y logros.
- Juegos con reglas comprensibles en una frase y controles táctiles.
- Persistencia local mediante AsyncStorage.
- Identidad visual basada en azul TEL, crema, acentos celestes y logo oficial.
- Mascota Telix como guía emocional y mecánica de retorno.

## Technical Stack

- Expo SDK 54, React Native 0.81, React 19.1.
- Expo Router, TypeScript estricto y ESLint Expo.
- AsyncStorage para perfil y resultados.
- Jest 29 + jest-expo para pruebas unitarias.
- Futuro realtime recomendado: Supabase.
